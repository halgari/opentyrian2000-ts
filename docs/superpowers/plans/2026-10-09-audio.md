# Audio Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Sample-exact OPL2/LDS music plus SFX for the TS port, playing in the browser through an AudioWorklet.

**Architecture:** A pure-TS `AudioEngine` (OPL emulator + LDS player + mixer) ported 1:1 from `opl.c`, `lds_play.c` and `loudness.c`, and verified against PCM rendered by a C harness built from the pinned reference. An AudioWorklet hosts the engine. A `WebAudio` class implements the game's `Audio` interface by message passing.

**Tech Stack:** TypeScript, vitest, Vite (`?worker&url` for the worklet), Web Audio API, C (gcc) for the oracle harness.

**Spec:** `docs/superpowers/specs/2026-10-09-audio-design.md`

## Global Constraints

- Every ported function carries a `// port of <fn> (<file>.c)` comment. All files start with `// SPDX-License-Identifier: GPL-2.0-or-later`. `opl.ts` keeps the DOSBox LGPL-2.1+ notice as well, since LGPL code can be combined into GPL.
- No module-level mutable state. All C globals become instance fields.
- C reference sources: `reference/opentyrian2000/src/` at commit `aad5aca01af139c0b089237c38ef765f7a84355d`. Read the C file you port in full.
- C integer semantics are mandatory:
  - `Bitu`/`Bits` are 64-bit on the oracle build (x86_64 `uintptr_t`/`intptr_t`). `Bit32u`/`Bit32s`/`Bit16s`/`Uint8`/`Uint16` wrap at their width.
  - Use `>>> 0`, `| 0`, `& 0xff`, `& 0xffff` and the helpers in `src/core/int.ts` exactly where the C would wrap or truncate.
  - Integer division of signed values truncates toward zero. Use `idiv` from `src/core/int.ts` or `Math.trunc`.
  - `double` math is plain JS number math. `float` math needs `Math.fround` at every point where C stores or computes a float.
- Golden tests use `describe.skip` when their input files are absent, following `test/helpers/data.ts` `describeData`.
- Commands: `pnpm test`, `pnpm typecheck`. Both must pass before every commit.
- Commit messages end with: `Claude-Session: https://claude.ai/code/session_01JXJ4hjEXrGM5Vja2B6e4Wz`

## Review Focus

1. **Silent 32/64-bit wrap mismatch in the OPL port.** A `Bitu` counter that the C lets grow past 2^32 but the TS truncates, or the reverse, makes the output drift after many seconds. The golden tests render 10 s and a full song loop to catch late drift.
2. **Audio before the start gesture, or a missing AudioWorklet.** The page must still boot silently, with a warning, never an error screen. This needs a test in Task 6 where `WebAudio` creation throws and falls back to NullAudio.
3. **`playSong` with an out-of-range song.** The C prints a warning and leaves the previous song state. TS must not throw (Task 5 test).
4. **Toggling `musicDisabled`/`samplesDisabled` at runtime.** The four mixer branches in `audioCallback` must match exactly (Task 5 tests).
5. **Chunk-size independence.** Rendering in 128-frame worklet blocks must equal rendering in 1024-sample chunks (Task 5 test). Otherwise browser output differs from the oracle-verified path.

### Task 3: OPL2 emulator port

**Files:**
- Create: `src/audio/opl.ts`
- Test: `test/audio/opl.test.ts`

**Interfaces:**
- Consumes: `CRand` (Task 1).
- Produces:
  ```ts
  class Opl {
    constructor(rand: CRand);
    init(sampleRate: number): void;                 // adlib_init
    write(idx: number, val: number): void;          // adlib_write
    getSample(out: Int16Array, offset: number, n: number): void; // adlib_getsample into out[offset..offset+n)
    regRead(port: number): number;                  // adlib_reg_read
    writeIndex(port: number, val: number): void;    // adlib_write_index
  }
  ```

- [ ] **Step 1:** Read `opl.c` fully. Port with `OPLTYPE_IS_OPL3` **undefined**; confirm it is not defined in `opl.h` or the Makefile.
  - **Where state lives:** every file-static (operator arrays, tables, `adlibreg`, `wave_sel`, LFO positions, `generator_add`, …) becomes a field. Lookup tables built in `adlib_init` may be computed once per instance.
  - **Operator records:** `op_type` becomes a class with numeric fields. Pointer fields (`cur_wform`) become `(table, offset)` pairs; `wform` pointer arithmetic indexes into a single `Int16Array` wavetable.
  - **Integer widths:** for every variable, check its C type. `Bit32u` arithmetic wraps with `>>> 0`, `Bit32s` with `| 0`. `Bitu`/`Bits` are 64-bit: keep them as plain numbers and assert in a comment that values stay < 2^53. `fltype` (double) math stays as JS doubles. Where the C casts double to integer, the TS truncates.
  - **Library functions:** `pow`, `sin` and `exp` in table generation use `Math.pow`, `Math.sin` and `Math.exp`. If golden tests in Task 4 show a mismatch, compare the tables first.
  - **Noise:** `rand()&1` becomes `this.rand.rand() & 1`.
- [ ] **Step 2:** Unit tests:
  - after `init(44100)`, rendering 1000 samples with no writes gives all zeros;
  - a simple tone (register writes for channel 0: 0x20=0x01, 0x40=0x10, 0x60=0xF0, 0x80=0x77, 0xA0=0x98, 0x23=0x01, 0x43=0x00, 0x63=0xF0, 0x83=0x77, 0xB0=0x31) gives non-zero output with period ≈ 44100/ (freq) — assert zero-crossing count within 5% of the expected count for f-num 0x198 block 4: f = 0x198 × 49716 / 2^(20-4) ≈ 309.1 Hz;
  - `getSample` into an offset writes only that range;
  - two instances with the same writes give identical output.
- [ ] **Step 3:** Run `pnpm test` and `pnpm typecheck`, then commit `feat(audio): port DOSBox OPL2 emulator`. Exactness is proven in Task 4.

### Task 5: Sound file, mixer engine, mixed golden

**Files:**
- Create: `src/audio/sound-file.ts`, `src/audio/engine.ts`, `src/audio/volume.ts`
- Test: `test/audio/sound-file.test.ts`, `test/audio/engine.test.ts`, `test/audio/volume.test.ts`, `test/golden/audio-mixed.test.ts`

**Interfaces:**
- Consumes: Tasks 1–4.
- Produces:
  ```ts
  // sound-file.ts — port of loadSndFile
  function loadSounds(tyrianSnd: Uint8Array, voicesSnd: Uint8Array, outputRate: number): Int16Array[]; // SOUND_COUNT entries
  function resampleS8(src: Int8Array, outputRate: number): Int16Array; // s8 -> s16 (v<<8), linear interp, length round(n*rate/11025)
  // engine.ts — port of loudness.c
  class AudioEngine {
    constructor(sampleRate: number);
    readonly sampleRate: number;
    musicDisabled: boolean; samplesDisabled: boolean;
    songPlaying: number;            // song_playing, starts 0
    get playing(): boolean;         // lds playing
    get songlooped(): boolean;
    get musicStopped(): boolean;
    loadMusic(bytes: Uint8Array): void;                 // load_music
    loadSounds(sounds: Int16Array[]): void;
    playSong(n: number): void; restartSong(): void; stopSong(): void; fadeSong(): void;
    setVolume(music: number, sample: number): void;
    multiSamplePlay(soundIndex0: number, chan: number, vol: number): void;
    playSample(n: number): void;    // JE_playSampleNum: multiSamplePlay(n-1, 0, FX_PLAY_VOL)
    render(out: Int16Array): void;  // audioCallback
  }
  // volume.ts — port of JE_changeVolume
  function changeVolume(music: number, musicDelta: number, sample: number, sampleDelta: number, playSample: (n: number) => void): { music: number; sample: number };
  ```

- [ ] **Step 1: `sound-file` tests.** With real data: 40 entries; voice entries are `(rawLen - 100) * 4` long at 44100, or 0 if the raw length is under 100. With synthetic data: a wrong count throws `Error('Unexpected data was read from a file.')`. **resampleS8:** `[0, 64]` → length 8, with the first output 0. Interpolation is between src[i] and src[i+1], and the final source sample holds for its 4 outputs (`[0,4096,8192,12288,16384,16384,16384,16384]`).
- [ ] **Step 2: Engine port.** `render` is a 1:1 port of `audioCallback`, including:
  - the four branches: music on or off × samples on or off;
  - the zero fill when music is stopped or disabled;
  - `musicVolumeFactor *= 2`;
  - `sampleVolumeFactors[i] = sampleVolumeFactor * (i + 1) / 8`, an integer division on Sint32;
  - per-channel pointer and count advance;
  - `FIXED_TO_INT` as an arithmetic `>> 12`;
  - the clamp.

  Other rules:
  - **Overflow:** the `Sint32` accumulator never exceeds 2^31 in practice. Use `| 0` where the C would wrap anyway.
  - **Channels:** a channel is `(samples: Int16Array, pos, remaining)`.
  - **`playSong`:** follows the C, including `song_num != song_playing` gating the load. Out-of-range songs warn through `console.warn` without throwing, and `songPlaying` is still set.
  - **Initial state:** `music_stopped = true`, `song_playing = 0`, volumes 255/255, as the C statics are.
- [ ] **Step 3: Engine unit tests.**
  - **Silence:** when music is stopped and no samples are playing, the output is zero.
  - **Single sample:** `multiSamplePlay` of a constant 1000 sample at chan 0, vol 7, sample volume 255, with music stopped, outputs `(1000 * 4096 * 8 / 8) >> 12 = 1000` until the sample is exhausted, then 0.
  - **Replacement:** a second `multiSamplePlay` on the same channel replaces the first.
  - **Volume levels:** vol 3 gives `1000 * (4096*4/8) >> 12 = 500`.
  - **Clamp:** a sum over 32767 clamps.
  - **Disabled samples:** `samplesDisabled` ignores `multiSamplePlay`, which is the early return in the C.
  - **Chunk independence:** after `playSong(29)`, rendering 44100 samples in one call equals rendering them in 128-sample calls.
  - **Out of range:** `playSong(99)` doesn't throw.
- [ ] **Step 4:** `volume.test.ts`:
  - `changeVolume(250, 10, 100, 0, spy)` returns `{music: 255, sample: 100}` and plays `S_CLINK` once;
  - a negative result clamps to 0 with a clink;
  - a zero delta never clinks.
- [ ] **Step 5:** Golden `audio-mixed.test.ts` for `title-mixed` and `title-fade`, plus `voltable`, which is compared to `buildVolumeFactorTable()`. Each uses an `AudioEngine` with `samplesDisabled = true`, `setVolume(v, 255)`, `loadMusic` and `playSong(song)`. The fade test calls `fadeSong()` at the scenario's `fadeAt` boundary, rendering in 1024-sample chunks. The result must equal the oracle exactly.
- [ ] **Step 6:** Commit `feat(audio): sound files, mixer engine; mixed music matches oracle`.

### Task 6: Browser integration (worklet + WebAudio)

**Files:**
- Create: `src/audio/protocol.ts`, `src/audio/worklet.ts`, `src/platform/web-audio.ts`
- Modify: `src/platform/audio.ts`, `src/assets.ts`, `src/main.ts`, `src/ctx.ts`, `src/screens/title.ts` (import ids from `src/audio/ids` only if needed), `README.md` (Status)
- Test: `test/platform/web-audio.test.ts`, `test/audio/worklet-host.test.ts`

**Interfaces:**
- Consumes: `AudioEngine`, `loadSounds`, ids.
- Produces:
  - **`Audio` interface:** as in spec §3.6. `NullAudio` implements it with `playing=false`, `songlooped=false`, `songPlaying=0`, and both disabled flags false.
  - **`protocol.ts`:**
    ```ts
    type ToWorklet =
      | { t: 'init'; music: Uint8Array; sounds: Int16Array[] }
      | { t: 'playSong'; n: number } | { t: 'restartSong' } | { t: 'stopSong' } | { t: 'fadeSong' }
      | { t: 'setVolume'; music: number; sample: number }
      | { t: 'multiSamplePlay'; index: number; chan: number; vol: number }
      | { t: 'flags'; musicDisabled: boolean; samplesDisabled: boolean };
    type FromWorklet = { t: 'status'; playing: boolean; songlooped: boolean; songPlaying: number; peak: number };
    class EngineHost { constructor(engine: AudioEngine, post: (m: FromWorklet) => void); handle(m: ToWorklet): void; process(out: Float32Array): void }
    ```
    `process` renders into an internal Int16Array, converts with `/ 32768`, and posts `status` when `playing`, `songlooped` or `songPlaying` changes. It also posts at most every 0.5 s of audio with `peak`, the max abs value over that window, used by the debug hook.
  - **`worklet.ts`:** registers `'tyrian-audio'`. Its processor builds an `AudioEngine(sampleRate)` and an `EngineHost` that relays `port.onmessage` messages. `process()` writes channel 0 and returns true.
  - **`web-audio.ts`:** `static async create(ctx: AudioContext, music: Uint8Array, tyrianSnd: Uint8Array, voicesSnd: Uint8Array): Promise<WebAudio>`.
    - It loads the worklet via `import workletUrl from '../audio/worklet.ts?worker&url'` and `audioWorklet.addModule(workletUrl)`.
    - It decodes sounds on the main thread with `loadSounds(…, ctx.sampleRate)` and posts `init`.
    - The node is created with `outputChannelCount: [1]` and connected to the destination.
    - Methods post messages. Getters return the mirrored status. `playSample(n)` posts `multiSamplePlay(n-1, 0, FX_PLAY_VOL)`.
    - Setting `musicDisabled`/`samplesDisabled` posts `flags`.
  - **main.ts:** at the start gesture, synchronously inside the handler, creates `new AudioContext({ sampleRate: 44100 })` and calls `resume()`. After the gesture it `await`s `WebAudio.create(...)` inside try/catch. On failure it does `console.warn` and falls back to `new NullAudio()`. The audio goes to `createCtx({ audio })`, then `audio.setVolume(191, 191)`; this is the C config default, and the comment says so. When `location.search` includes `debug`, it sets `window.__audio = { get peak() {…}, get playing() {…} }`.
  - **assets.ts:** gains `music: Uint8Array` (`music.mus`), `tyrianSnd` and `voicesSnd` (`voices.snd`, since xmas is off).
