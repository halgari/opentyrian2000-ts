> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Finish the port so every mode a single machine can play in the C game works in the browser (ENGAGE/SuperTyrian, galaga, timed battle, 2-player arcade, title codes, gamepads, Graphics setup and Jukebox), harden the browser layer, and ship it as a static site and as one `tyrian.html`.

Build and hosting are post-build scripts and config files; nothing is deployed.

/** One tyrian.sav holding `slots`; every other slot stays empty. */
export function buildSeedSave(slots: SeedSlot[]): Uint8Array {
  const ctx = seedCtx();
  const g = ctx.game, c = g.config;
  for (const s of slots) {
    initEpisode(ctx, s.episode);
    g.items.initialEpisodeNum = s.initialEpisode ?? s.episode;
